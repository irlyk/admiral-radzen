# Участие в проекте

Основной язык документации — русский; английский перевод `README.en.md` обновляйте после русской версии. Имена API и программные идентификаторы остаются без перевода.

Перед изменением ознакомьтесь с [AGENTS.md](AGENTS.md) и [стилем кода](docs/component-code-style.md). Сохраняйте архитектуру трёх независимо версионируемых пакетов, публичный API и маршруты smoke. Для новых сторонних ресурсов сохраняйте условия лицензии и необходимые уведомления.

Выбирайте проверки по области изменения: для документации проверьте ссылки и `git diff --check`; для кода выполните соответствующую сборку и затронутые тесты. Команды приведены в [README](README.md). Если среда не позволяет выполнить проверку, укажите это в описании изменения. Не объявляйте визуальное соответствие без проверки реально отрисованного интерфейса.

В pull request укажите назначение, затронутые пакеты и страницы, результаты проверок и ограничения. Не добавляйте секреты, ключи, персональные данные или локальные артефакты. Публикацию NuGet и изменение прав на ресурсы выполняет владелец после отдельного решения.
