# Регресс, часть 1 — подготовка выпуска

Совместимые исправления после опубликованного комплекта 2.0.0 и новые
параметры компоновки и состояний меню. Этот PR готовит пакеты к выпуску;
публикация NuGet и GitHub Release выполняется отдельно после успешного CI.

| Пакет | Новая версия | Изменение |
| --- | --- | --- |
| AdmiralRadzen.Components | 2.1.0 | MINOR: новые совместимые параметры и исправления компонентов |
| AdmiralRadzen.Themes | 2.0.1 | PATCH: исправления Admiral и прямых Radzen-компонентов |
| AdmiralRadzen.Icons | 2.0.1 | PATCH: обновление динамических SVG без повреждения Blazor DOM |

Components зависит от Icons 2.0.1, Themes 2.0.1 и Radzen.Blazor 12.0.6.
Целевая платформа остаётся .NET 10. Идентификаторы пакетов, пространства имён
и пути `_content/Radzen.Admiral.*` сохраняются.

## Исправления

- Поля ввода: связи label/input, сохранение фокуса, автоматическая высота
  TextArea, доступное состояние ошибки NumberInput, сброс видимости пароля,
  закрытие Select при потере корректного положения и события только для
  изменившихся границ DateRangePicker.
- PhoneNumberInput: обновление флага после выбора страны, видимый клавиатурный
  фокус, стабильная ширина пустого результата поиска и расширенный стандартный
  каталог стран. Явный выбор страны сохраняется при общем телефонном коде.
- Кнопки и группы: disabled/loading/skeleton, доступные имена, стабильные
  размеры, независимые действия и цвета взаимодействия. Добавлены проверки
  Admiral и прямых Radzen-кнопок с темой.
- FloatingButton и меню: динамические SVG, позиционирование относительно
  viewport, внешнее управление открытием, состояния дополнительных действий,
  индикаторы раскрытия и восстановление фокуса.
- Layout: необязательные header/sidebar/body/footer, работоспособный
  HeaderHeight, настройка ширины sidebar и высоты footer, корректные границы
  вложенного меню и затемнения, уникальные ID и клавиатурное управление.
- Grid: единое определение SCSS, сохранение span внутри Layout, исправленные
  переносы примеров и самостоятельная сетка в статической документации.
- Theme-only: выравнивание leaf/branch в RadzenTree, disabled у кнопок,
  отсутствие полосы после сворачивания sidebar и читаемые цвета тёмной темы.
- Hint и Tooltip: корректное закрытие при уходе фокуса и связь подсказки
  с фактически сфокусированным элементом.

## Новые возможности и совместимость

- AdmiralLayout: Footer, FooterHeight, CustomSideMenuWidth, FooterClass,
  FooterStyle и UseBodyGrid. Пресеты SideMenuWidth сохраняются;
  CustomSideMenuWidth имеет приоритет. UseBodyGrid по умолчанию true,
  а false включает обычный поток блоков.
- MultiButton: DisabledMainButton и Skeleton; TextButtonMenu: Loading
  и Skeleton; AdmiralMenu: Disabled. Ранее доступные параметры сохраняются.
- Стандартный каталог стран PhoneNumberInput расширен. Приложения с фиксированным
  набором стран могут продолжать передавать собственный Countries.
- SideMenuId по умолчанию уникален для каждого Layout. Если приложение
  обращается к sidebar по фиксированному ID, задайте SideMenuId явно.
- Footer и header отсутствующих секций не резервируют место. Отсутствующий
  SideMenu также не создаёт пустую колонку. Прямые GridItem внутри body
  сохраняют свои responsive span.

Примеры размеров и theme-only API находятся в [руководстве компонентов](../components.md)
и на страницах Layout/Grid в smoke и WASM. Переход с Themes 1.x по-прежнему
требует учитывать удаление файлов шрифтов в 2.0.0; см. [подключение шрифтов](../fonts.md).

## Документация и проверка

Добавлены общие страницы Basics, цветов, подключения, Switch, кнопочных меню
и Layout для server smoke и статического WASM. Исправлены ссылки и сетка
под project subpath GitHub Pages.

Регрессии перенесены в C#/NUnit/Microsoft.Playwright: page objects, типизированные
снимки геометрии и стилей, отдельные проверки пакетов, NuGet consumer,
компиляции Razor-примеров и WASM. CI отдельно запускает категорию Button.
Проверки затрагивают RU/EN, light/dark, клавиатуру и адаптивные размеры.

Это первая часть исправлений. Полная сверка всех компонентов с Admiral
и проверка всех вариантов прямого Radzen продолжаются в следующих выпусках.
Порядок выпуска и обязательные проверки описаны в [инструкции релиза](../releasing.md).
