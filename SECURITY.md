# Сообщения о проблемах безопасности

Не публикуйте действующие секреты, персональные данные или технические детали эксплуатации уязвимости в открытом issue или pull request.

Если ошибка не раскрывает чувствительную информацию, создайте issue с шагами воспроизведения, версией пакета и ожидаемым результатом. Для конфиденциального сообщения используйте приватный канал репозитория, если он доступен; если его нет, не размещайте детали в открытом обсуждении.
