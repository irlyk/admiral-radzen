# Галерея AdmiralConsumerSmoke

Проверочное Blazor Server-приложение и документация компонентов.
Подключает Admiral и Radzen через `PackageReference`, а не напрямую из
исходников. Так проверяется реальное потребление NuGet-пакетов:
сборки, CSS, JavaScript, шрифты и SVG.

## Запуск

Из корня репозитория выполните [сборку и запуск](../../README.md#сборка-и-запуск).
Важно сначала собрать локальные пакеты, затем решение.
Галерея доступна по адресу [http://localhost:5072](http://localhost:5072).

После изменения библиотеки пересоберите пакеты, обновите их в smoke и
перезапустите сервер. Если версия пакета не изменилась, NuGet может использовать
старую распакованную сборку; подробности —
[обновление и диагностика](../../docs/radzen-integration.md#обновление-и-диагностика).

## Как пользоваться

Страницы компонентов содержат три раздела: интерактивный пример Admiral,
вариант на прямом Radzen с классами темы и документацию API.
Проверяйте обе темы и переключение русского/английского языка.

Основные страницы:

| Адрес | Содержимое |
| --- | --- |
| `/` | Обзор галереи |
| `/buttons` | Кнопки, размеры и состояния |
| `/tables` | Таблицы, действия, фильтры и пагинация |
| `/components/typography` | Типографика, в том числе китайский и корейский текст |
| `/icons` | Поиск и копирование идентификаторов иконок |
| `/coverage` | Покрытие компонентов Admiral |

Остальные страницы доступны через боковое меню. Галерея — не шаблон
производственного приложения: данные и сценарии загрузки демонстрационные.

## Что проверять

- Геометрию, перенос текста и шрифты в светлой и тёмной темах.
- Hover, focus, hover + focus, active, selected, disabled, loading и error.
- Tab, стрелки, Enter, Space, Escape и документированные сочетания.
- События и шаблоны Admiral, а также отдельные примеры прямого Radzen.
- Загрузку пакетов без файлов из соседних репозиториев.

Проверка ресурсов после запуска (должны возвращать HTTP 200 и непустое тело):

```text
/_content/Radzen.Admiral.Themes/css/admiral-dark-base.css
/_content/Radzen.Admiral.Themes/fonts/SourceSans3VF-Upright.ttf.woff2
/_content/Radzen.Admiral.Themes/fonts/MaterialSymbolsOutlined.woff2
/_content/Radzen.Admiral.Icons/admiral-radzen-icons.css
/_content/Radzen.Admiral.Icons/admiral-icons/icons.txt
/_content/Radzen.Admiral.Icons/admiral-icons/system/search-outline.svg
```

[Автоматизированные проверки и демо Radzen](../../docs/radzen-regression.md)
дополняют ручной просмотр. Поведение и ограничения компонентов описаны в
[справочнике](../../docs/components.md).
